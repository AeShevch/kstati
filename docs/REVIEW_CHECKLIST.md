# Чеклист ревью

Для каждого изменения разработчик или агент кратко фиксирует:

- Какой пользовательский сценарий или технический инвариант меняется; какой OpenSpec change это разрешает.
- Сохранились ли границы модулей, один основной тип на файл и соседство тестов с исходниками.
- Затронуты ли оригиналы записей, подтверждённые значения, SQL-схема или миграции; если да, какие проверки защищают данные.
- Какие тесты добавлены или обновлены и какие режимы `scripts/ios-checks.sh` прошли локально.
- Зелёные ли проверки GitHub Actions; при UI-сбое приложен ли `xcresult` и разобрана ли причина.

Команды и версии инструментов приведены в [инструкции тестирования](../ios/TESTING.md).
