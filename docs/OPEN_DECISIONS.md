# Открытые решения

Эти вопросы в исходных материалах не согласованы. Они не должны превращаться в скрытые допущения при реализации.

| Решение | Почему открыто | Когда закрыть |
|---|---|---|
| Главный экран: «Сегодня» или крупная кнопка «Кстати» | Продуктовая концепция называет главным экраном «Сегодня», архитектура — одну крупную кнопку | До change ежедневника/навигации |
| Простое геонапоминание в первом релизе | Концепция включает его в MVP, архитектурный MVP перечисляет только уведомления по времени | До change уведомлений |
| Apple Calendar в первой версии | Концепция оставляет вопрос открытым; архитектура откладывает полноценную внешнюю интеграцию | До change ежедневника |
| Хранение вложений в App Group и резервное копирование | Не заданы формат, защита и восстановление | До реализации Share Extension |
| Cloud AI consent и серверная аутентификация | Чувствительные записи могут быть исключены; протокол согласия и лимиты ещё не определены | До AI backend change |
| Частота подсказок и состав «Сегодня» | Открытые продуктовые решения в концепции | До context engine и ежедневника |
| Типовые скриншоты для проверки OCR/AI | Концепция просит выбрать три типа на реальных примерах | До AI evaluation |

Минимальная версия iOS 17.0 для первого проекта принята в [ADR-009](../openspec/adr/009-ios-17-target.md). Для первого change выбраны локальные сценарии. Формат хранения вложений в App Group описан в design change; вопросы защиты, восстановления и резервного копирования остаются открыты.
