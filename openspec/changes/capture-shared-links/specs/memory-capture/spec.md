# Spec Delta

## ADDED Requirements

### Requirement: Сохранение веб-ссылки из Share Extension
Расширение «Поделиться» SHALL принимать один адрес `http` или `https` и сохранять его как исходную запись локально без зависимости от сети. Оно SHALL показывать успех только после подтверждённого сохранения.

#### Scenario: Ссылка сохранена без сети
- **GIVEN** iPhone не подключён к сети
- **WHEN** пользователь передаёт веб-ссылку в «Кстати» через «Поделиться» и нажимает «Сохранить»
- **THEN** расширение подтверждает локальное сохранение, а ссылка доступна в приложении после перезапуска

#### Scenario: Неподдерживаемый адрес
- **WHEN** переданный адрес не является ссылкой `http` или `https`
- **THEN** расширение сообщает, что адрес не поддерживается, и не создаёт запись

#### Scenario: Ошибка локального сохранения
- **WHEN** расширение не может сохранить ссылку локально
- **THEN** оно сообщает об ошибке, оставляет возможность повторить действие и не подтверждает успех
