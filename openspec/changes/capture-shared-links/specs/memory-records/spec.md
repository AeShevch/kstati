# Spec Delta

## ADDED Requirements

### Requirement: Исходная веб-ссылка остаётся доступной
Система SHALL хранить исходный адрес веб-ссылки без подмены заголовком или результатом обработки. Пользователь SHALL видеть адрес в карточке и иметь возможность открыть его явным действием.

#### Scenario: Открытие после перезапуска
- **GIVEN** пользователь сохранил веб-ссылку и перезапустил приложение
- **WHEN** он открывает карточку записи
- **THEN** приложение показывает исходный адрес и действие для открытия страницы

#### Scenario: Пользователь открывает страницу
- **GIVEN** карточка ссылки открыта
- **WHEN** пользователь выбирает открытие страницы
- **THEN** iOS получает исходный адрес для открытия

#### Scenario: Нет автоматического обращения к странице
- **GIVEN** пользователь сохранил ссылку
- **WHEN** он просматривает карточку без действия открытия
- **THEN** сохранение и просмотр не требуют загрузки страницы или передачи адреса в backend
