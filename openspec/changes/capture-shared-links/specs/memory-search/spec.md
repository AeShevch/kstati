# Spec Delta

## ADDED Requirements

### Requirement: Веб-ссылка находится по адресу и домену
Приложение SHALL находить сохранённые ссылки по адресу и домену локально, без запроса к странице или backend. Результат SHALL вести к карточке с исходным адресом.

#### Scenario: Поиск по домену без сети
- **GIVEN** сохранена ссылка `https://example.com/article` и iPhone не подключён к сети
- **WHEN** пользователь ищет `example.com`
- **THEN** ссылка появляется в результатах и открывает карточку с исходным адресом

#### Scenario: Поиск по адресу
- **GIVEN** сохранена ссылка `https://example.com/article`
- **WHEN** пользователь ищет `article`
- **THEN** ссылка появляется в результатах

#### Scenario: Ссылка удалена
- **GIVEN** пользователь удалил сохранённую ссылку
- **WHEN** он ищет её адрес или домен
- **THEN** удалённая ссылка не появляется в результатах
