# Proposal

## Why

Сейчас «Кстати» принимает через «Поделиться» только изображения, хотя ссылки входят в базовый сценарий быстрого захвата. Пользователь должен сохранить адрес страницы без открытия приложения и найти его позже даже без сети.

## What Changes

- Share Extension принимает одну веб-ссылку `http` или `https`, явно подтверждает локальное сохранение и сообщает об ошибке без ложного успеха.
- Приложение хранит исходный URL как оригинал записи, показывает его в карточке и открывает по явному действию пользователя.
- Локальный поиск находит ссылку по адресу и домену; повторная обработка одного события передачи не создаёт дубль.
- Получение заголовка страницы, предпросмотр, сетевой запрос, AI-анализ, экспорт и восстановление данных не входят в этот change.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `memory-capture`: сохранение веб-ссылки через Share Extension и результат ошибки.
- `memory-records`: исходный URL как доступный после перезапуска оригинал записи.
- `memory-search`: локальный поиск ссылок по адресу и домену с переходом к исходной записи.

## Impact

Затронуты `MemoryCore`, миграция `MemoryPersistence`, Share Extension, отображение записи в iOS и UI-тесты. Сетевой backend и внешние API не требуются. Решение следует ADR-001, ADR-002 и ADR-003; исходный URL остаётся локальным источником истины.
