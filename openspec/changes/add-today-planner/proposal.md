# Proposal

## Why

Сохранённая запись может содержать действие или событие. Пользователю нужен способ явно назначить дату и увидеть план на текущий день.

## What Changes

- Добавить отдельный экран «Сегодня» с переходом из «Памяти».
- Создавать задачу или событие из карточки записи после явного подтверждения. Задачу можно оставить без даты.
- Показывать задачи и события на текущий день, отмечать задачи выполненными и менять даты.
- Интеграцию с Apple Calendar, напоминания и автоматическое извлечение вынести в отдельные изменения.

## Capabilities

### New Capabilities

- `today-planner` — локальные задачи, события и план дня.

### Modified Capabilities

## Impact

Доменные модели, SQLite, карточка записи, навигация SwiftUI и тесты iOS.
