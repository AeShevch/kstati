# Spec Delta

## Purpose

Помогает превратить изображение в пригодный для поиска текст, сохраняя контроль пользователя над итоговыми данными и исходным файлом.

## ADDED Requirements

### Requirement: Локальное распознавание текста
Для сохранённого изображения приложение SHALL предлагать распознанный текст без отправки исходного изображения во внешний сервис.

#### Scenario: OCR распознал текст
- **WHEN** пользователь открывает сохранённое изображение с читаемым текстом
- **THEN** приложение показывает предложенный текст для проверки и оставляет оригинал доступным

#### Scenario: OCR не распознал текст
- **WHEN** распознавание изображения завершилось без текста или ошибкой
- **THEN** оригинал остаётся сохранённым, а пользователь может ввести описание вручную

### Requirement: Подтверждение и исправление
Приложение SHALL различать предложенный распознаванием текст и значения, подтверждённые пользователем; правка SHALL не менять оригинал.

#### Scenario: Пользователь исправляет результат OCR
- **GIVEN** OCR предложил текст с ошибкой
- **WHEN** пользователь исправляет его и подтверждает
- **THEN** исправленный текст сохраняется как подтверждённый и используется для поиска; исходное изображение остаётся прежним

#### Scenario: Пользователь отклоняет предложение
- **WHEN** пользователь удаляет предложенный OCR текст и сохраняет запись
- **THEN** запись и оригинал остаются доступны без подтверждённого текста
