# Proposal

## Why

Задача или событие в «Сегодня» остаётся пассивным, пока пользователь сам не откроет приложение. Напоминание помогает вовремя вернуться к конкретному плану.

## What Changes

- Добавить одно добровольное локальное напоминание по времени для датированной задачи или события.
- Показывать время, причину и состояние напоминания в редакторе. Разрешить выключить его в любой момент.
- При переносе на другой день и при выполнении задачи отменять прежнее уведомление. Для новой даты пользователь может заново включить напоминание.
- Геонапоминания и повторяющиеся уведомления выделить в отдельные изменения.

## Capabilities

### New Capabilities

- `local-reminders` — локальные уведомления, привязанные к плану.

### Modified Capabilities

## Impact

Редактор планов, SQLite, системные уведомления iOS и тесты. Зависит от `add-today-planner`.
