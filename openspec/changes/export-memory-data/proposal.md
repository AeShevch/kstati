# Proposal

## Why

Пользователю нужна переносимая копия записей и оригиналов, которую можно сохранить вне приложения.

## What Changes

- Добавить явный офлайн экспорт всех сохранённых записей, групп и оригиналов в один файл через системный выбор места сохранения.
- Импорт, восстановление, автоматическое резервное копирование и удаление данных находятся вне границ этого change.

## Capabilities

### New Capabilities

- `memory-export` — выгрузка локальной памяти в переносимый архив.

### Modified Capabilities

## Impact

iOS, локальный репозиторий, работа с файлами и тесты. Порядок интеграции — после захвата ссылок.
