# Spec Delta

## Purpose

Пользователь может выгрузить локальную память в переносимый файл и сохранить его вне приложения.

## ADDED Requirements

### Requirement: Экспорт локальной памяти
Приложение SHALL по явному действию пользователя подготовить один переносимый архив без сетевых запросов и предложить сохранить его через системный интерфейс iOS.

#### Scenario: Экспорт без сети
- **GIVEN** сохранены текст, изображение, веб-ссылка и группы
- **WHEN** пользователь запускает экспорт офлайн и выбирает локальное место сохранения
- **THEN** файл содержит записи, подтверждённые поля, оригиналы, исходные байты вложений, группы и связи между ними
- **AND** оригиналы и подтверждённые поля представлены раздельно

#### Scenario: Пустая память
- **WHEN** пользователь экспортирует пустую память
- **THEN** приложение позволяет сохранить корректный архив с пустыми списками записей и групп

### Requirement: Экспорт сохраняет исходные данные
Экспорт SHALL оставлять исходные записи и вложения без изменений. Приложение MUST показывать успешный результат только после подтверждения сохранения системой.

#### Scenario: Отмена сохранения
- **WHEN** пользователь отменяет системный выбор места сохранения
- **THEN** приложение возвращается к исходному экрану без сообщения об успехе

#### Scenario: Ошибка подготовки
- **WHEN** оригинал невозможно прочитать или архив невозможно записать
- **THEN** приложение сообщает об ошибке и позволяет повторить экспорт
- **AND** приложение не предлагает неполный архив
