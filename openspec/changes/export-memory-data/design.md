# Design

## Context

Локальный репозиторий хранит записи и связи в SQLite, изображения в файлах App Group. Экспорт следует ADR-001, ADR-002, ADR-003 и ADR-006.

## Goals / Non-Goals

**Goals:** Переносимый файл с согласованным снимком локальных данных.

**Non-Goals:** Миграция схемы SQLite, импорт, восстановление и фоновое резервное копирование.

## Decisions

- ZIP с UTF-8 JSON-манифестом и полем версии формата. Манифест содержит стабильные идентификаторы, даты, оригиналы текста и URL, подтверждённые поля, группы и связи. Изображения лежат отдельными файлами с относительными путями в манифесте. Такой формат открывается обычным архиватором и не зависит от схемы SQLite. Выгрузка одной базы потребовала бы отдельно собирать файлы и учитывать детали SQLite.
- Получать метаданные одним снимком чтения. Если нужный файл исчезнет при параллельном удалении, завершить экспорт ошибкой. Пропуск файла привёл бы к неполной выгрузке.
- Собирать архив во временной папке приложения вне главного потока и отдавать его системному интерфейсу экспорта. Удалять временный файл после завершения, ошибки или отмены. Системный интерфейс даёт пользователю выбор места сохранения.

## Risks / Trade-offs

- Большие вложения могут расходовать память и место → читать файлы по частям и обрабатывать нехватку места как ошибку.
- Архив содержит личные данные → явно сообщить о содержимом до сохранения. Файл получает защиту выбранного пользователем места хранения.
