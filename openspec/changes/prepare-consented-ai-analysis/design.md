# Design

## Context

Память уже хранит подтверждённый текст, а ежедневник принимает вручную подтверждённые планы. Границы сохраняют ADR-002, ADR-003 и ADR-004.

## Decisions

- Передавать снимок одного подтверждённого текста, показанного в диалоге. Редактирование записи после показа требует повторного просмотра. Для пустого текста предложить сначала подтвердить описание.
- Зафиксировать один маршрут анализа в OpenAPI. Вход содержит текст и контекст гражданской даты, выход содержит ограниченный список предложений с типом, заголовком и необязательной датой. Событие без даты требует ручного заполнения. Клиент и сервер проверяют ограничения, ответ считается недоверенными данными.
- Использовать NestJS и `LlmPort` с детерминированным адаптером только в среде разработки и CI. Доступ к маршруту в релизной конфигурации закрыт до отдельного решения об аутентификации и квотах.
- Держать предложения в состоянии экрана и переиспользовать редактор планов для сохранения. Применять результат только к тому снимку записи, который пользователь подтвердил.

## Risks / Trade-offs

- Запрос может завершиться после ухода со страницы → отменить клиентскую операцию и отбросить поздний ответ.
- Подробные журналы могут раскрыть текст → логировать только код результата и время обработки.
