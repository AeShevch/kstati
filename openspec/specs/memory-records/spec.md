# memory-records Specification

## Purpose

Сохраняет исходные материалы и подтверждённые пользователем сведения на устройстве, позволяя группировать записи без дублирования оригиналов.

## Requirements

### Requirement: Оригинал и подтверждённые данные сохраняются отдельно
Система SHALL хранить оригинал записи и исправленные пользователем данные раздельно; производные сведения SHALL быть пересоздаваемыми без изменения оригинала.

#### Scenario: Исправление текста
- **GIVEN** сохранено изображение с распознанным текстом
- **WHEN** пользователь исправляет подтверждённый текст
- **THEN** изображение и его исходные байты не меняются

### Requirement: Запись доступна после перезапуска
Система SHALL сохранять запись и её оригинал на устройстве до явного удаления пользователем.

#### Scenario: Перезапуск приложения
- **GIVEN** пользователь сохранил запись и закрыл приложение
- **WHEN** пользователь запускает приложение снова
- **THEN** запись, её подтверждённые поля и оригинал доступны

### Requirement: Динамические группы
Пользователь SHALL иметь возможность создавать группы и добавлять одну запись в несколько групп без копирования записи.

#### Scenario: Одна запись в двух группах
- **WHEN** пользователь добавляет запись в две созданные им группы
- **THEN** обе группы показывают одну и ту же запись и один оригинал

#### Scenario: Удаление группы
- **GIVEN** запись принадлежит группе
- **WHEN** пользователь удаляет группу
- **THEN** сама запись и оригинал остаются доступны вне удалённой группы

### Requirement: Явное удаление записи
Пользователь SHALL иметь возможность удалить запись вместе с её локальным оригиналом и связями.

#### Scenario: Удаление записи
- **WHEN** пользователь подтверждает удаление записи
- **THEN** запись исчезает из списка, групп и поиска, а её локальный оригинал удаляется
