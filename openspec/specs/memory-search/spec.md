# memory-search Specification

## Purpose

Позволяет находить сохранённые записи по подтверждённому тексту и возвращаться от результата к исходному материалу без подключения к сети.

## Requirements

### Requirement: Текстовый поиск работает локально
Приложение SHALL искать сохранённые записи по подтверждённому тексту без сетевого запроса.

#### Scenario: Поиск без сети
- **GIVEN** пользователь сохранил запись с подтверждённым текстом «купить шампунь» и отключил сеть
- **WHEN** он ищет «шампунь»
- **THEN** запись появляется в результатах

#### Scenario: Нет совпадений
- **WHEN** пользователь ищет текст, которого нет в сохранённых записях
- **THEN** приложение показывает пустой результат без ошибки

### Requirement: Результат открывает оригинал
Каждый результат SHALL открывать связанную запись и её исходный текст или изображение.

#### Scenario: Открытие найденного скриншота
- **GIVEN** найден результат для сохранённого скриншота
- **WHEN** пользователь открывает результат
- **THEN** приложение показывает карточку и исходное изображение

### Requirement: Поиск отражает правки и удаление
Результаты SHALL соответствовать текущему подтверждённому тексту и существующим записям.

#### Scenario: Текст исправлен
- **GIVEN** пользователь изменил подтверждённый текст записи с «врач» на «дерматолог»
- **WHEN** он ищет «дерматолог»
- **THEN** исправленная запись находится

#### Scenario: Запись удалена
- **GIVEN** пользователь удалил запись
- **WHEN** он ищет текст из удалённой записи
- **THEN** удалённая запись не появляется
