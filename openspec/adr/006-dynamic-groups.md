# ADR-006 — Динамические группы many-to-many

**Статус:** принято как архитектурный baseline 04.11.2026.

## Решение

Пользователь создаёт свои группы; система может предлагать группы по содержимому. Одна `MemoryItem` может принадлежать нескольким группам и хранится при этом один раз.

## Последствия

Модель содержит связь N:M. Удаление группы удаляет связи, но не запись и не оригинал. AI-предложение группы не подменяет выбор пользователя.
